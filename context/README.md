# NextStay — Context Hub (рабочая память Claude + Атая)

Эта папка — **общий контекст и журнал прогресса** по проекту NextStay (PMS для отелей),
который мы доводим до конца ради отчёта по Software Engineering (160+ страниц).

> Зона ответственности Атая = всё **[DB]** (база данных, схемы, миграции, seed/синтетика, dbt/DWH).
> Плюс новая задача: **симулятор синхронизации данных отелей** (+ возможно примитивный сайт бронирования).

## Файлы

| Файл | Назначение |
|---|---|
| `PROJECT.md` | Паспорт проекта: стек, 6 схем БД, поток данных |
| `GOALS.md` | Цели, спринты, задачи Атая, требования к отчёту, новая задача-симулятор |
| `STATE.md` | Снимок текущего состояния: что реализовано / что в работе / что осталось |
| `PROGRESS.md` | Хронологический журнал изменений (дополняем каждую сессию, сверху новое) |
| `DECISIONS.md` | Зафиксированные технические решения и их обоснование |
| `REPORT-OUTLINE.md` | План отчёта (160+ стр.): разделы, диаграммы, что добавить от Атая |

## Правила ведения

1. После каждого значимого шага — запись в `PROGRESS.md` (дата, что сделано, что дальше).
2. Технические решения с обоснованием — в `DECISIONS.md`.
3. Диаграммы — Mermaid (рендерятся в Word/GitHub/mermaid.live). Везде, где помогает пониманию процесса.
4. Даты — абсолютные (сегодня для справки: 2026-06-12).

## Среда / заметки по инструментам

- Рабочая директория сессии зафиксирована как `~/Desktop/mticket`; с NextStay работаем по **абсолютным путям**.
- `cd` за пределы рабочей директории и `find` по дереву NextStay спотыкаются о sandbox — использовать `ls`, `Read`, `Glob`, прямые абсолютные пути.
